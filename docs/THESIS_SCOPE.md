# Thesis examination scope

This file distinguishes the examiner-facing manuscript from the repository's technical and audit records. Supporting documents remain available for reproducibility but should not be inserted wholesale into the main thesis.

## Examiner-facing chapters

- `METHODOLOGY.md`
- `RESULTS.md`
- `CONCLUSION.md`

These chapters contain the study design, evidence, interpretation, limitations, contribution, and conclusions. An assembled submission must also include the institutionally required front matter, introduction, literature review, references, and appendices; those components are not identified as separate manuscript files in this repository.

## Technical companions

- `REQUIREMENTS_SPECIFICATION.md`
- `REPRODUCIBILITY.md`
- `ANALYSIS_PIPELINE.md`
- `DATA_DICTIONARY.md`
- `DATA_MANAGEMENT.md`
- `MULTI_REGION_AMENDMENT.md`
- the repository `README.md`

These documents contain implementation settings, requirement traceability, operational recovery procedures, version history, table contracts, and exact reproduction commands. They may be cited or selectively excerpted in an appendix when required, but they are not part of the central examiner-facing argument.

## Artifact boundary

The main thesis should contain only the tables and figures needed to answer the research questions. Complete CSV outputs, manifests, hashes, test inventories, failed-run records, superseded analyses, and dashboard implementation details remain repository evidence. Private raw responses and identifier-bearing records must never be included in a submission or public supplement.
